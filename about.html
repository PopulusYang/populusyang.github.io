关于猎人小屋

这是一个记录食堂菜品、评分与随机抽取结果的小站，目标是让“今天吃什么”这件事少一点纠结。

这个站点做什么

猎人小屋主要提供三个入口：随机摇骰决定今天吃什么、查看已评测菜品、以及在首页浏览友情链接。

数据从哪里来

菜品数据由本地生成的 SQLite 数据库 menu.db 提供，网页端通过 sql.js 读取后渲染到浏览器中。

静态托管方式

本站使用 GitHub Pages 进行静态托管，不运行传统后端服务。页面、友链和数据库文件都作为静态资源发布，由浏览器直接读取和展示。

友情链接和图标

首页底部的友情链接来自 links.json，可选图标字段为 icon_path。

维护方式

本地通过 Python 脚本管理数据：manage_db.py 管菜品，manage_links.py 管友情链接。

GitHub 仓库维护

本站的代码、页面、数据和图片都在 GitHub 仓库中统一维护，仓库地址为 github.com/PopulusYang/populusyang.github.io.git。每次更新后通过提交并推送到主分支完成发布。
